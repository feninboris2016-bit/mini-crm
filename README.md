# 🚀 Мини-CRM для сбора и обработки заявок с сайта

Полнофункциональная, автономная, защищённая веб-система (CRM) для сбора, обработки и учёта заявок с одного сайта с личным кабинетом администратора, базой данных (PostgreSQL / SQLite), независимыми Email и Telegram уведомлениями с очередью повторных попыток, комментариями к лидам, защищённым экспортом в CSV и системой резервного копирования.

---

## 🌟 Ключевые возможности

- 🛡️ **Защищённая авторизация**: вход по email/паролю, хеширование паролей адаптивным алгоритмом `bcrypt` (12 раундов), подписанные JWT-токены, защита от перебора паролей (Brute-Force Protection).
- 📥 **Публичный версионированный API** (`POST /api/v1/leads`):
  - Приём заявок со статичных сайтов и лендингов.
  - Серверная валидация и нормализация контактов (телефон/email).
  - Защита от спам-ботов через `Honeypot` (поле-ловушку) и `Rate Limiting`.
  - Поддержка ключа идемпотентности (`X-Idempotency-Key` / `external_idempotency_key`) для предотвращения дублей при повторных кликах.
  - Проверка ключа доступа сайта (`X-Site-Key`).
- ⚡ **Двухканальная независимая очередь уведомлений**:
  - Отдельные фоновые задачи для **Email** (SMTP) и **Telegram** (Telegram Bot API).
  - Сбой одного канала не блокирует другой.
  - Экспоненциальная задержка при повторах (1 мин, 5 мин, 15 мин, 60 мин, до 5 попыток).
  - Возможность ручного повтора отправки из интерфейса.
  - Маскирование секретов в логах ошибок.
- 👥 **Интерфейс CRM (React + TypeScript)**:
  - 📋 **Интерактивная Канбан-доска (Kanban Pipeline)**:
    - Визуальные колонки воронки продаж: `Новые`, `В работе`, `Переговоры`, `Успешно`, `Отказ`.
    - Подсчёт количества лидов и суммарного бюджета сделок в каждом этапе.
    - Drag-and-Drop перемещение карточек между колонками с визуальным индикатором ("Поставить сюда").
    - Быстрый выбор этапа в 1 клик прямо на карточке для мобильных устройств.
  - 🌡️ **Степень прогрева (Температура лида)**:
    - 3 градации: ❄️ Холодный (`cold`), ⚠️ Требует внимания (`attention`), 🌟 Тёплый/Готов покупать (`good`).
    - Цветовые акценты на карточках (`border-l-4`).
    - Кнопки переключения температуры в 1 клик прямо на карточке без открытия модального окна.
    - Автоматический контроль "зависших" заявок: лиды без движения более 2 дней помечаются бейджем "⚠️ Без движения".
  - 💰 **Бюджет и сумма сделки**:
    - Учёт стоимости сделки в рублях (`₽`), автоматическое суммирование по стадиям и общий объём воронки.
  - 👤 **Ответственный менеджер**:
    - Назначение ответственного сотрудника прямо из карточки и фильтрация по менеджерам.
  - ➕ **Ручное добавление лидов**:
    - Модальное окно создания заявки прямо из интерфейса (клиенты по звонку, из офлайна или мессенджеров).
  - 🔍 **Продвинутая панель фильтрации**:
    - Поиск по имени, номеру, email, заметкам и менеджеру.
    - Фильтрация по статусам, температуре, источнику, менеджеру и датам.
  - 🔄 **Переключатель режимов отображения**:
    - Мгновенное переключение между **Канбан-доской** и **Таблицей заявок**.
  - **Сводка**: общая статистика заявок, объём воронки, выигранные сделки, состояние очередей и интеграций.
  - **Карточка лида**: редактирование бюджета, температуры, ответственного, планирование звонков (`next_call_at`), быстрый звонок по ссылке `tel:`, удаление заявки, добавление внутренних заметок, история уведомлений.
- 📊 **Экспорт в CSV**:
  - Экспорт с учётом текущих поисковых фильтров.
  - Формат **UTF-8 с BOM** (`\uFEFF`) — корректное открытие кириллицы в Microsoft Excel без кракозябр.
  - **Защита от CSV Formula Injection** (CWE-1236) — экранирование символов `=`, `+`, `-`, `@`.
- 💾 **Резервное копирование и восстановление**:
  - Создание структурированных снимков базы данных прямо из веб-интерфейса или через CLI.
  - Восстановление данных с проверкой целостности в транзакции.
- ⚙️ **Динамические настройки**:
  - Настройка параметров SMTP и Telegram без перезапуска сервера.
  - Маскирование паролей и токенов (`••••••••`).
  - Тестовые кнопки проверки связи с почтой и Telegram-ботом.

## 🛠️ Стек технологий

- **Backend**: Node.js v22/v24, TypeScript, Express.
- **Frontend**: React 18, TypeScript, Vite.
- **Database**: PostgreSQL (Neon, Supabase, Render, Railway, любой Postgres) или встроенная локальная SQLite для разработки и автономной работы.
- **Queue / Worker**: Server-side in-process worker + внешний Cron webhook (`POST /api/v1/jobs/process-queue`).
- **Тесты**: Vitest (26 автоматизированных тестов, 100% прохождение).

## 🚀 Быстрый старт локально

### 1. Установка зависимостей
```bash
npm install
```

### 2. Настройка переменных окружения
Скопируйте пример файла конфигурации:
```bash
cp .env.example .env
```
*(По умолчанию сервер уже готов к запуску со встроенной базой данных `data/crm.sqlite`).*

### 3. Создание первого администратора
Запустите интерактивный CLI-скрипт создания учетной записи (пароль не вшивается в исходный код!):
```bash
npm run create-admin -- admin@crm.local your_secure_password_123
```

### 4. Запуск в режиме разработки
```bash
# Запуск backend и frontend вместе:
npm run dev
```
После запуска откройте в браузере: **http://localhost:3000**  
Войдите под созданным email и паролем администратора.

### 5. Сборка и запуск в production
```bash
npm run build
npm start
```

## 🔌 Подключение сайта к CRM

Для отправки заявок с вашего сайта используйте версионированный endpoint `POST /api/v1/leads`:

```javascript
fetch('http://localhost:3000/api/v1/leads', {
  method: 'POST',
  headers: {
    'Content-Type': 'application/json',
    'X-Site-Key': 'tristar_site_api_key_2026' // ваш ключ из настроек CRM
  },
  body: JSON.stringify({
    name: 'Иван Иванов',
    phone: '+7 (999) 000-00-00',
    email: 'client@mail.ru',
    message: 'Интересует покупка компьютера',
    source_name: 'Форма контактов',
    source_url: window.location.href,
    _hp_bio: '' // honeypot поле: обязательно пустое!
  })
});
```
Готовый HTML/JS сниппет формы также доступен прямо в интерфейсе CRM по кнопке **«🔌 Подключить сайт»** в шапке.
